# HW1 - отчёт

## Регулярные выражения

Полный список находится в `tokens.json`. Основные выражения:

- `WS = [ \t\r\n]+`
- `COMMENT = //[^\r\n]*`
- `IDENT = [A-Za-z][A-Za-z0-9]*`
- `INT = 0|[1-9][0-9]*`
- ключевые слова: `function`, `returns`, `requires`, `ensures`, `uses`, `if`, `else`, `while`, `invariant`, `assert`, `assume`, `forall`, `exists`, `not`, `and`, `or`, `true`, `false`, `int`, `length`
- операторы и разделители заданы отдельными regex в `tokens.json` (включая `->`, `=>`, `:`, `|`).

## Построение

1. Regex разбираются собственным parser-ом.
2. Для каждого regex строится НКА Томпсона.
3. НКА объединяются одним стартовым состоянием.
4. Выполняется subset construction → ДКА.
5. ДКА дополняется trap-state.
6. Выполняется минимизация алгоритмом Хопкрофта.
7. Таблица переходов сериализуется в JSON.

## Размеры

- НКА: **295 состояний**
- ДКА до минимизации: **125 состояний**
- ДКА после минимизации: **122 состояния**
- Алфавит: **ASCII, 128 символов**
- Trap-state: **1**

## Принимающие состояния

Каждое принимающее состояние хранит идентификатор токена. Если несколько regex подходят одной строке, применяется приоритет из `tokens.json`, то есть порядок объявления токенов. При этом сначала действует longest-match. Поэтому `function` → `FUNCTION`, но `function1` → `IDENT`.

## Skip

`WS` и `COMMENT` распознаются автоматом, но lexer не возвращает их пользователю (`skip=true`).

## Тестирование

Запуск:

```bash
python3 src/main.py test
```

Результат текущего запуска: **34/34 теста пройдено**.

Проверены пустая строка, пробелы/табы/CRLF, `0`, отрицательный `01`, идентификаторы, отклонение `_` (в реальной грамматике Funny идентификатор — это буква и далее буквы/цифры, без подчёркивания), ключевые слова, все требуемые операторы/разделители (включая `->` и `=>` для формул `identifier(...) => predicate`), комментарии, longest-match и trap/non-ASCII случаи.

## Связь с T0

Файл `output/minimized_dfa.json` содержит стартовое состояние, trap-state, принимающие состояния и полную таблицу переходов `state × ASCII-symbol`. Его можно использовать как таблицу переходов будущего лексера.
